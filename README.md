# easy_bc

A simple Python project for behavior cloning policies.

## Structure

- `src/easy_bc/`: Core package code.
  - `__init__.py`: Package initialization.
  - `policies.py`: Policy implementations.
- `train.py`: Script to train policies.
- `tests/`: Unit tests for the package.

## Usage

Install dependencies, then run `train.py` to train a policy.
